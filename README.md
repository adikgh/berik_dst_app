# Berik POS · Раздача (iOS + Android)

Раздача сайтының (dist.pf.c) мобильді программасы, Flutter-де жазылған. Бір код iPhone-ға да, Android-қа да жиналады.

## Ішінде не бар
- Кіру (телефон + құпиясөз, тек Директор / Админ / Раздача)
- Жеткізу: Жаңа, Жолда, Аяқталған, курьер тағайындау, курьер бойынша сүзгі, 2GIS
- Өзімен, Сервис: «Берілді»
- Кафе: «Столда»
- Толығырақ: толық мәлімет, қоңырау, WhatsApp, статус тарихы, өзгерістер
- Аккаунт: тіл (ҚАЗ / РУС), Бас тарту тізімі, Курьерлер (қосу, өзгерту, өшіру), құпиясөз
- Жаңа тапсырыс түскенде дыбыспен хабарлама (программа ашық не фонда тұрғанда, әр 15 секунд)

## Сервер бөлігі
`server/api/index.php` файлын сайтқа `dist.pf.c/api/index.php` етіп көшіру керек. Базаға өзгеріс керек емес.
Қаласаңыз `config/secret.php` ішіне `'api_key' => 'ұзын-кездейсоқ-сөз'` қосыңыз (токен қолтаңбасы үшін).

## Жинау
GitHub → **Actions** → **build**. Әр `main`-ге push болғанда өзі жиналады.
Дайын файлдар жинаудың төменгі жағында, **Artifacts** бөлімінде:
- `razdacha-android` → `razdacha.apk`
- `razdacha-ios` → `razdacha.ipa`

Сервер мекенжайы: репо баптауларында **Settings → Secrets and variables → Actions → Variables** ішіне `API_URL` қосыңыз
(мысалы `https://dist.example.kz`). Программаның кіру бетінде де мекенжайды өзгертуге болады.

## Телефонға орнату
- **Android:** `razdacha.apk` файлын телефонға жіберіп, ашыңыз. «Белгісіз көздерден орнатуға» рұқсат беріңіз.
- **iPhone (Developer аккаунтсыз):** Windows-қа [Sideloadly](https://sideloadly.io) орнатыңыз, iPhone-ды кабельмен қосыңыз,
  `razdacha.ipa` файлын таңдап, өз Apple ID-іңізбен кіріңіз. Телефонда: Баптаулар → Негізгі → VPN және құрылғыны басқару → Apple ID-ге сенім білдіру.
  Тегін Apple ID-мен программа 7 күн жұмыс істейді, кейін қайта орнату керек.
- **App Store / TestFlight:** Apple Developer аккаунты керек (жылына $99).
